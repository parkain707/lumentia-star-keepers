# 루멘티아: 별의 파수꾼 (Lumentia: Star Keepers)
*오리지널 수집형 방치 RPG (HTML5 Canvas + WebAudio)*

---

## 🌟 개요 및 기획 사양
- **장르:** 수집형 방치 RPG (웹 브라우저 기반)
- **저작권 무결성:** 원작(G123 작안의 샤나)의 IP, 코드, 이미지, 음원을 전혀 사용하지 않고 100% 독자 구축한 오리지널 타이틀입니다.
- **아트 엔진:** 외부 이미지 에셋 0개. 순수 Canvas 2D 프로시저럴(절차적) 렌더링으로 캐릭터와 배경 구현.
- **오디오 엔진:** 외부 음원 파일 0개. 브라우저 WebAudio 신디사이저를 활용한 자체 효과음 생성.
- **데이터 보존:** 별도 DB 서버 없이 브라우저 `localStorage`에 자동 저장(5초 주기 및 창 전환 시 자동 세이브).

---

## 🎮 핵심 게임 룰 & 경제 체계
1. **재화 시스템**:
   - **미소 (Smile):** 전투 승리, 방치 수익, 업적 달성으로 획득하는 주력 육성 재화. (1회 보상 최대 20,000 미소 엄격 제한)
   - **별빛 (Starlight Gems):** 스테이지 클리어, 보스 처치, 업적을 통해 획득하는 가챠(동행 소환) 재화.
   - **성혼 (Shards):** 중복 동행 획득 시 지급되는 각성(별 승급) 재화.
2. **동행 육성 & 편성**:
   - 총 8종의 고유 클래스 동행 (검사, 수호자, 마도사, 성가대 등).
   - 레벨업 및 각성으로 기본 스탯(공격력, 방어력, 체력) 증폭.
   - 3인 파티 편성 시스템.
3. **전투 & 성좌 해방 (궁극기)**:
   - 자동 전투 진행 (일반 공격 + 개별 쿨타임 스킬 자동 시전).
   - 전투 중 축적되는 게이지로 오른쪽 아래 '성좌 해방' 궁극기 발동 가능.
4. **오프라인 방치 보상**:
   - 자리를 비운 시간 동안 최대 8시간 분량의 미소 자동 축적 및 접속 시 정산.

---

## 🚀 실행 방법
- **방법 1 (원클릭 실행):** `run_game.bat` 파일을 더블클릭하면 로컬 서버가 시작되고 기본 브라우저에서 게임이 즉시 열립니다.
- **방법 2 (단독 실행):** `index.html` 파일을 크롬, 엣지 등 모던 웹 브라우저로 직접 더블클릭하여 실행해도 플레이 가능합니다.

G:\starlight-idle\

    ├── battle.js       # 실시간 전투 시뮬레이션 및 틱 계산기
