# 루멘티아: 별의 파수꾼 (Lumentia: Star Keepers)
*오리지널 수집형 도전 RPG (HTML5 Canvas + WebAudio)*

## 개편 버전의 도전과 보상 규칙

- 한국 시간 기준 하루 2회 도전합니다. 시작할 때 1회 차감하고 매 도전은 스테이지 1에서 시작합니다.
- 수령·전멸·75초 시간 초과로 도전이 종료됩니다. 자동 재도전은 없으며, 진행 중 새로고침하면 체력·적·궁극기·남은 시간을 복원합니다.
- **성장 미소**는 영웅 육성용 지갑입니다. 처치·클리어·임무·자동 수익·휴식 보상을 모두 합쳐 한국 시간 기준 하루 최대 20,000미소까지만 획득합니다. 신규 계정의 시작 미소 300도 첫날 집계에 포함합니다. 지갑에서 사용해도 오늘의 획득 한도는 늘어나지 않으며, 정상적으로 여러 날 모은 보유 잔액은 20,000을 넘을 수 있습니다. 청구서에는 포함되지 않습니다.
- **도전 금고 포인트**는 클리어할 때 적립됩니다. 패배하면 잃고, 안전 수령하면 별도의 **청구 보상 미소**로 확정됩니다. 지급 전환은 1P = 1미소입니다.
- 청구 보상은 두 도전 합계 하루 최대 20,000미소입니다. 하루 합계 5,000미소 이상을 얻는 구간은 시작 편성을 반영한 극한 난도입니다. 두 번째 도전에도 첫 번째 수령액을 반영합니다.
- **미소 수령 인증서는 선생님 클래스톡으로 보내야 효력이 발생합니다.** 복사·저장·화면 캡처만으로는 제출되지 않습니다. 복사 버튼은 복사 이력만 기록하며, 학생이 실제 클래스톡 전송 후 별도 확인 버튼으로 제출 기록을 남깁니다. 이 버튼은 자동 전송이나 교사의 수신 확인을 대신하지 않습니다. 실제 효력과 지급 여부는 선생님의 클래스톡 수신 내역을 기준으로 합니다.
- 수령 확정 후 72시간 내 클래스톡으로 제출하지 않으면 해당 보상은 0미소로 만료됩니다. 복사만 한 보상도 계속 만료 대상입니다. 기존 버전의 청구 기록은 유지하되 클래스톡 수신 여부를 별도로 확인하도록 표시합니다.
- 청구서와 날짜별 기록에는 해당 날짜의 확정 보상만 표시합니다. 이미 청구한 금액과 이번 청구액을 구분하며 동일 정산 번호는 중복 지급하지 않습니다.
- 첫 이용자는 무료 소환 → 성장 → 도전 → 금고 수령 → 청구의 5단계를 화면 위 안내 버튼으로 진행합니다.

### 기존 기록 승계

기존 계정의 원본 저장 문자열을 같은 브라우저의 `기존저장키.before-v2`에 먼저 백업합니다. 성장 획득 한도 정책 전환 전 원본은 별도로 `기존저장키.before-growth-cap-v1`에 백업합니다. 이전 정책에서 모인 미소 잔액은 한 번만 최대 20,000 성장 미소로 보정합니다. 이미 v2로 전환한 학생도 새 정책을 한 번 적용합니다. 영웅·레벨·각성·조각·파티·별빛·최고 기록·업적·성장 통계는 유지합니다.

접속 시 보정 전후 금액을 안내하며, 확인 전에는 자동 성장 수익과 진행 중 전투를 멈춥니다. 확인 후 원래 도전을 이어갑니다. 확인 이력은 저장해 다음 접속 때 같은 안내가 반복되지 않으며 설정에서 보정 내역을 다시 볼 수 있습니다. 정책 적용일에는 보정 후 보유액을 당일 성장 획득 집계의 시작값으로 삼고, 다음 한국 시간 자정부터 새 한도를 적용합니다. 이후 여러 날 정상적으로 모은 잔액은 재접속만으로 다시 보정하지 않습니다.

기존 미확정 금고와 방치 대기액은 청구 보상으로 옮기지 않습니다. 명시적인 당일 안전 수령 기록과 사용 횟수만 승계합니다. 성장 미소 획득 한도와 청구 보상 한도는 각각 하루 20,000이며 서로 독립적입니다. 임무 보상에 필요한 성장 한도가 부족하면 임무를 수령 가능 상태로 유지하여 다음 날 수령할 수 있습니다.

현재 저장·만료 시간·횟수 제한은 브라우저 저장소와 기기 시계를 사용합니다. 같은 브라우저의 기존 기기별 도전 제한도 유지합니다. 여러 기기의 학생별 통합 횟수 관리, 교사 지급 승인, 서버 서명 인증서는 별도의 서버 연동이 필요합니다.

### 실행과 검증

Node.js 환경에서 `npm test`로 보상·승계·종료·복원·만료 테스트를 실행하고, `npm run dev`로 로컬 검토 서버를 실행합니다. 외부 npm 의존성은 없습니다. `node tests/balance-probe.cjs`로 편성별 고위험 구간을 재현할 수 있습니다. 테스트용 가상 계정 생성 화면은 로컬 개발 서버에만 있으며 Vercel 배포 파일에서는 제외합니다.

## 🌟 개요 및 기획 사양
- **장르:** 수집형 방치 RPG (웹 브라우저 기반)
- **저작권 무결성:** 원작(G123 작안의 샤나)의 IP, 코드, 이미지, 음원을 전혀 사용하지 않고 100% 독자 구축한 오리지널 타이틀입니다.
- **아트 엔진:** 외부 이미지 에셋 0개. 순수 Canvas 2D 프로시저럴(절차적) 렌더링으로 캐릭터와 배경 구현.
- **오디오 엔진:** 외부 음원 파일 0개. 브라우저 WebAudio 신디사이저를 활용한 자체 효과음 생성.
- **데이터 보존:** 별도 DB 서버 없이 브라우저 `localStorage`에 자동 저장(1초 주기 및 창 전환 시 자동 세이브).

## 🎮 핵심 게임 룰 & 경제 체계
1. **재화 시스템**:
   - **성장 미소:** 전투·방치·업적으로 획득하는 육성 재화. 선생님께 청구하는 보상 미소와 별도입니다.
   - **별빛 (Starlight Gems):** 스테이지 클리어, 보스 처치, 업적을 통해 획득하는 가챠(동행 소환) 재화.
   - **성혼 (Shards):** 중복 동행 획득 시 지급되는 각성(별 승급) 재화.
2. **동행 육성 & 편성**:
   - 총 8종의 고유 클래스 동행 (검사, 수호자, 마도사, 성가대 등).
   - 레벨업 및 각성으로 기본 스탯(공격력, 방어력, 체력) 증폭.
   - 3인 파티 편성 시스템.
3. **전투 & 성좌 해방 (궁극기)**:
   - 자동 전투 진행 (일반 공격 + 개별 쿨타임 스킬 자동 시전).
   - 전투 중 축적되는 게이지로 오른쪽 아래 '성좌 해방' 궁극기 발동 가능.
4. **오프라인 방치 보상**:
   - 자리를 비운 시간 동안 최대 8시간 분량의 미소 자동 축적 및 접속 시 정산.

## 🚀 실행 방법
- **방법 1 (원클릭 실행):** `run_game.bat` 파일을 더블클릭하면 로컬 서버가 시작되고 기본 브라우저에서 게임이 즉시 열립니다.
- **방법 2 (단독 실행):** `index.html` 파일을 크롬, 엣지 등 모던 웹 브라우저로 직접 더블클릭하여 실행해도 플레이 가능합니다.
